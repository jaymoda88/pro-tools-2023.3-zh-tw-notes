- [Ch45c — ElasticProperties與轉檔邊界](PT-Ch45c-ElasticProperties%E8%88%87%E8%BD%89%E6%AA%94%E9%82%8A%E7%95%8C.md) — 處理結果不對時，先查來源 Tempo、Meter 與 Event Sensitivity，別把錯誤 metadata 當成演算法音質不夠好。
### Ch46 — Melodyne 與 Audio to MIDI

- [Ch46 — Melodyne整合與Audio轉MIDI](PT-Ch46-Melodyne%E6%95%B4%E5%90%88%E8%88%87Audio%E8%BD%89MIDI.md) — Melodyne 整合讓你直接在 Edit window 改 Audio，但 Audio to MIDI 擷取的是演奏資料，不是把原音色複製成另一種檔案。
### Ch47 — Commit、Freeze 與 Bounce Track

- [Ch47a — Commit固定處理與交接](PT-Ch47a-Commit%E5%9B%BA%E5%AE%9A%E8%99%95%E7%90%86%E8%88%87%E4%BA%A4%E6%8E%A5.md) — Commit 把目前處理結果變成新的 Audio Track，讓修改、運算負擔與交接相依性各有清楚的邊界。
- [Ch47b — Freeze與TrackBounce的使用時機](PT-Ch47b-Freeze%E8%88%87TrackBounce%E7%9A%84%E4%BD%BF%E7%94%A8%E6%99%82%E6%A9%9F.md) — Freeze 暫停修改來換運算資源，Track Bounce 則把結果交成檔案；先選目的，再選命令。
### Ch48 — Event Operation

- [Ch48a — Quantize與Groove的節奏整理](PT-Ch48a-Quantize%E8%88%87Groove%E7%9A%84%E7%AF%80%E5%A5%8F%E6%95%B4%E7%90%86.md) — Quantize 不是把所有事件硬吸到線上，而是指定哪些事件、朝哪個時間參考、移動多少。

### Ch49 — HEAT

- [Ch49 — HEAT的音色與資源管理](PT-Ch49-HEAT%E7%9A%84%E9%9F%B3%E8%89%B2%E8%88%87%E8%B3%87%E6%BA%90%E7%AE%A1%E7%90%86.md) — HEAT 用一組全域 Drive 與 Tone 改變 Audio Track 的非線性色彩，效果取決於輸入，也取決於它放在 Insert 前還是後。
### Ch50 — 混音基礎

- [Ch50a — 混音Track與訊號流](PT-Ch50a-%E6%B7%B7%E9%9F%B3Track%E8%88%87%E8%A8%8A%E8%99%9F%E6%B5%81.md) — Audio、Aux、Master Fader 與 VCA 都能改變混音，卻只有先看清楚訊號是否真的流過它們，才不會接錯。
- [Ch50b — Sends與混音視窗操作](PT-Ch50b-Sends%E8%88%87%E6%B7%B7%E9%9F%B3%E8%A6%96%E7%AA%97%E6%93%8D%E4%BD%9C.md) — Send 把訊號分出去，卻不會自動替你建立回程；聲音在哪裡消失，沿著來源、Send、目的地三段查最有效。
- [Ch50c — Submix效果回傳與耳機混音](PT-Ch50c-Submix%E6%95%88%E6%9E%9C%E5%9B%9E%E5%82%B3%E8%88%87%E8%80%B3%E6%A9%9F%E6%B7%B7%E9%9F%B3.md) — Submix 把多個來源送到共同處理點；先分清是取代原聲的串接，還是與原聲並存的效果回傳。
- [Ch50d — DelayCompensation與Dither](PT-Ch50d-DelayCompensation%E8%88%87Dither.md) — Delay Compensation 對齊不同路徑，Dither 處理降 bit depth 的量化行為；兩者都在保護結果，卻各自有明確邊界。
### Ch51 — Plug-In 與 Hardware Insert

- [Ch51a — PlugInInsert與SideChain](PT-Ch51a-PlugInInsert%E8%88%87SideChain.md) — Insert 是串在訊號路上的處理；弄清楚順序、格式與旁路狀態，才能知道你比較的到底是哪一個聲音。

### Ch52 — DSP Mode

- [Ch53b — Automation錄寫與保護](PT-Ch53b-Automation%E9%8C%84%E5%AF%AB%E8%88%87%E4%BF%9D%E8%AD%B7.md) — 可靠的 automation pass 要同時開啟參數、Track mode 與正確的操作焦點，保護也要選對是停寫還是停讀。

- [Ch53d — WriteTo快照與Preview工作流](PT-Ch53d-WriteTo%E5%BF%AB%E7%85%A7%E8%88%87Preview%E5%B7%A5%E4%BD%9C%E6%B5%81.md) — 先 audition、再固定，是處理複雜 automation 的好方法；Write To、Snapshot、Preview 與 Capture 各自負責不同階段。
- [Ch53e — VCAAutomation與Coalesce](PT-Ch53e-VCAAutomation%E8%88%87Coalesce.md) — VCA 的變化與成員原本的 automation 可以共存；Coalesce 才把兩層正式合成成員自己的資料。

- [Ch58b — Object控制與空間Automation](PT-Ch58b-Object%E6%8E%A7%E5%88%B6%E8%88%87%E7%A9%BA%E9%96%93Automation.md) — Object Track 上同時存在普通 Output 與 Object Output，真正走哪一條，取決於 Bus/Object toggle 與控制模式。
