## 檔案結構

| 位置 | 用途 |
|---|---|
| `read/` | GitHub 可直接閱讀的 Markdown 版本；已轉換內部連結與圖片嵌入 |
| `notes/` | 保留原始 Obsidian Markdown、wikilinks、callouts、Dataview／Tasks 語法 |
